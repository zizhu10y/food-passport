# 🛂 美食护照 Food Passport

一本属于吃货的电子护照：每吃到一道新菜，就在对应国家的页面上点亮它、盖一个章。
奖励的是**吃到新东西**，不是**吃得贵**。

👉 **在线使用：<https://zizhu10y.github.io/food-passport/>**

- 💸 完全免费，不用注册、不用登录
- 📱 可以安装到手机主屏幕，全屏打开，像一个 App
- ✈️ 打开过一次之后，**不联网也能用**
- 🔒 记录只存在你自己的手机上，不会上传到任何地方

---

## 📲 安装到手机

第一次需要联网打开一次：

| 手机 | 步骤 |
|---|---|
| **iPhone** | 用 **Safari** 打开上面的网址 → 点底部「分享」→「添加到主屏幕」 |
| **Android** | 用 **Chrome** 打开 → 右上角菜单 →「安装应用」或「添加到主屏幕」 |

装好后桌面上会出现金色碗筷图标的「美食护照」。之后开飞行模式也能照常使用（只有店铺的地图链接需要联网）。

## ✨ 功能

### 🌍 18 个国家，251 道菜 + 37 种饮料
中国、日本、韩国、越南、泰国、马来西亚、印度尼西亚、菲律宾、印度、尼泊尔、黎巴嫩、土耳其、希腊、意大利、法国、西班牙、墨西哥、澳大利亚。

- 打开 App 时，护照会自己翻开（一秒多一点），点一下屏幕可以跳过。
- 每个国家的页面分成 **菜品 / 饮料 / 去哪吃** 三个标签，菜**按代表程度排序**，标签上显示这一类吃过几道。
- 每道菜都有一张彩铅手账风插画：没吃过时只是淡棕色虚线草稿，盖章后颜色一笔一笔涂上去。
- 菜品卡片写着味道、主要食材、一句小知识，以及是否平价 💸、能否在家做 🏠。

### 🖋️ 盖章
- 吃到一道菜就点「盖章」：记录日期、花费、在哪吃的、一句评价。
- 两种印章：🍽️ 外食章、🏠 家厨章。每个国家的印章颜色和形状不同，每次盖下去角度和墨迹都不一样。
- 拍张照，会在手机上自动变成同样的彩铅风插画，替换原来的图。
- $10 以内吃到新菜，额外得到金色「≤$10」徽章。

### 🎲 随机挑战
抽一道还没吃过的菜或饮料。先选抽菜品、饮料还是都行（默认只抽菜品），再按地区、想要的味道、不想吃的味道（比如"不要辣"）、只要平价或能在家做来筛选。
- 点抽到的卡片看详情；「再抽一次」和改筛选都只刷新那一块，页面不会跳回顶部。
- 接受挑战时选期限：今天 / 3 天内 / 本周内 / 不限时。
- 期限内盖章算成功；过了期限算超时，中途换一道算放弃。
- 统计页有挑战战绩：成功、超时、放弃、成功率和连胜。失败不会扣任何成就，没完成的菜可以一键「再战」。

### 🔍 菜名识别
输入菜名，中英文都行，打错字也能找到（"chiken rice" → 海南鸡饭）。
- 🧬 **混血章**：融合菜，两国各盖一半。
- ❓ **神秘章**：认不出来的先盖问号章，以后再归类。

### 📍 去哪吃（悉尼 Burwood 一带）
几乎每道菜和饮料都推荐了一家店，一共 129 家：
- 优先选 Burwood 附近评分高、评论多的店。
- 附近没有好选择时，换成坐火车方便的店，并写明在哪站下。
- 国家页的「去哪吃」先显示 5 家（Burwood 附近、评分高的排在前面），点「看全部」展开。
- 通巴（尼泊尔）、薄荷汽水（法国）、陶罐咖啡（墨西哥）在悉尼还没找到确定有卖的店，先显示这个国家常去的区。
- 部分饮料没法确认店里一定有，备注里写着「去之前问一下」。
- 评分来自 Google Maps，菜品的店查询于 **2026-10-30**，新饮料的店查询于 **2026-11-03**，之后可能有变化，去之前请再看一眼营业时间和菜单。

### 🏅 成就与统计
初次出境、亚洲巡游、无辣不欢、忠实粉丝、穷鬼美食家、勇者、家厨达人、环游世界。
最后一页会显示"你用 $XX 吃遍了 X 个国家"，以及各国花费。

## 💾 备份记录

记录存在手机浏览器里。删除 App、清除浏览器数据都会丢失记录。
在「📊 统计 → 备份 / 同步」里可以**导出**一段文本或 .json 文件，换手机时再**导入**。

> iPhone 上，从主屏幕图标打开的 App 和在 Safari 里打开的网页是分开存储的，建议一直从主屏幕图标打开。

## 🛠️ 技术说明

- 纯前端：一个 HTML 文件（HTML + CSS + JavaScript），插画全部用 SVG 在代码里绘制，没有外部图片。
- `sw.js`：Service Worker，负责离线缓存。
- `manifest.webmanifest` 和图标：让它可以安装到主屏幕。
- `build.py`：从源文件 `food-passport.html` 生成这里的 `index.html`，加上安装和离线需要的部分。修改源文件后运行：

  ```bash
  python3 build.py
  ```

  然后提交推送，GitHub Pages 会自动更新。已安装的手机在下次联网打开时会拿到新版本。
